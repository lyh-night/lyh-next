# AI 修改指南

> AI Coding Agent 修改代码时的规范和检查清单。

---

## 一、修改原则

修改代码前：

1. 阅读相关目录
2. 理解已有实现
3. 保持现有风格
4. 最小化修改范围
5. 不随意重构

新增文件前，请先确认：是否已有类似模块可复用。

---

## 二、禁止事项

- 修改无关文件
- 重命名目录
- 引入重复依赖
- 复制粘贴已有逻辑
- 禁用 ESLint
- 禁用 TypeScript
- 大规模格式化整个项目

---

## 三、提交前检查

确认：

- TypeScript 无报错
- ESLint 通过
- 无未使用 import
- 无 `console.log`
- 无 `any`
- UI 风格一致
- Server / Client 边界正确
