# 首页设计文档

## 设计目标

作为 LLM 平台的首页，需要在第一时间传达平台核心价值，引导用户快速开始使用，并展示平台能力与生态。

---

## 模块详细设计

### 1. Hero Section

**目标**：一句话传递平台核心价值，引导用户行动

**内容**：

- 标题：平台 Slogan（如"释放 AI 的无限可能"）
- 副标题：一句话描述平台定位
- CTA 按钮：
  - 主按钮：「免费开始」/「立即体验」→ 跳转到聊天页或注册
  - 欉按钮：「查看文档」→ 跳转 API 文档
- 背景：渐变色或动态粒子效果（可选）

**设计要点**：

- 视觉冲击力强，留白充足
- CTA 按钮突出，颜色对比强烈
- 移动端自适应

---

### 2. Model Showcase（模型展示）

**目标**：展示平台提供的模型能力

**内容**：

- 模型卡片列表，每个卡片包含：
  - 模型名称（如 GPT-4、Claude、Llama 等）
  - 模型简介（能力描述）
  - 标签：`免费` / `最新` / `推荐`
  - 快速体验按钮 → 直接进入聊天
- 支持筛选：按能力（对话/代码/多模态）、价格、速度等

**交互**：

- 卡片 hover 效果：放大 + 阴影
- 点击卡片进入模型详情或直接对话

---

### 3. Feature Highlights（核心功能）

**目标**：展示平台差异化能力

**建议功能点**：

| 功能          | 描述                            |
| ------------- | ------------------------------- |
| 多模型切换    | 一个平台使用多种模型，按需选择  |
| Prompt 模板库 | 丰富的提示词模板，开箱即用      |
| 对话历史      | 完整保存聊天记录，随时回溯      |
| API 接入      | 简单的 API 接口，轻松集成到应用 |
| 团队协作      | 多人共享对话、Prompt、知识库    |
| 数据安全      | 端到端加密，企业级安全保障      |

**展示形式**：

- 左右交替布局（图 + 文字）
- 每个功能配一个图标/插图

---

### 4. Use Cases / Examples（使用场景）

**目标**：让用户快速理解平台能做什么

**场景卡片**：

| 场景       | 目标用户   | 示例                      |
| ---------- | ---------- | ------------------------- |
| 写作助手   | 内容创作者 | 自动生成文章、润色文案    |
| 代码助手   | 开发者     | 代码生成、Debug、代码审查 |
| 数据分析   | 分析师     | Excel 处理、数据可视化    |
| 学习辅导   | 学生/教师  | 知识问答、作业辅导        |
| 客服机器人 | 企业       | 智能客服、FAQ 自动回复    |

**展示形式**：

- 卡片网格（3 列或 2 列）
- 每个卡片：图标 + 场景名 + 一句话描述 + 「体验」按钮

---

### 5. Pricing Plans（定价方案）

**目标**：清晰展示各方案差异，引导付费

**方案设计**：

| 项目         | Free     | Pro         | Enterprise          |
| ------------ | -------- | ----------- | ------------------- |
| 价格         | ¥0/月    | ¥99/月      | 定制                |
| 每日对话次数 | 20       | 无限        | 无限                |
| 模型访问     | 基础模型 | 全部模型    | 全部模型 + 私有部署 |
| API 调用     | 1K 次/月 | 100K 次/月  | 无限制              |
| 对话历史     | 7 天     | 无限        | 无限                |
| 支持         | 社区     | 邮件 + 社区 | 专属客服            |

**展示形式**：

- 三列对比表格
- Pro 方案高亮推荐
- 年付折扣提示（如"年付享 8 折"）

---

### 6. Footer

**内容**：

- 平台 Logo + 简介
- 链接分组：
  - 产品：模型列表、定价、更新日志
  - 开发者：API 文档、SDK、GitHub
  - 公司：关于我们、博客、联系方式
  - 法律：隐私政策、服务条款
- 社交媒体图标：GitHub、Twitter、微信公众号
- 版权信息

## 技术规范

### 组件结构

```
src/app/home/
├── page.tsx              # 首页入口
├── components/
│   ├── hero/             # Hero 区块
│   ├── models/           # 模型展示
│   ├── features/         # 核心功能
│   ├── use-cases/        # 使用场景
│   ├── pricing/          # 定价方案
│   └── footer/           # 页脚
└── develop.md            # 本文档
```

### 样式规范

- 使用 Tailwind CSS
- 响应式断点：`sm` (640px)、`md` (768px)、`lg` (1024px)、`xl` (1280px)
- 主色调：与品牌色保持一致
- 字体：系统默认 + Inter（英文）
- 间距使用 4px 倍数系统

### 性能要求

- 首屏加载 < 2s（LCP）
- 使用 Next.js Image 组件优化图片
- Hero 背景动画使用 CSS 动画（避免 JS 开销）
- 模型数据使用 Server Component 渲染
